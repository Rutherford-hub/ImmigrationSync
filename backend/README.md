# Smart Immigration Processing & Tracking System (Group 65)

Welcome to the unified repository for the **Smart Immigration Processing & Tracking System**[cite: 1]. This project contains both the backend microservices and the Expo mobile application[cite: 1].

---

## 📂 Project Structure

* `/backend` - Spring Boot microservices running on individual ports[cite: 1].
* `/frontend` - Expo React Native app (TypeScript) for applicants and officers[cite: 1].
* `/init-scripts` & `docker-compose.yml` - Shared PostgreSQL database services.

---
